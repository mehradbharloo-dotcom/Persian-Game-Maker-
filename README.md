# Persian Game Maker

A browser-based Persian 3D scene editor with a desktop-style interface.

## Current prototype

- Persian right-to-left interface
- WebGL 3D viewport and grid
- Add cubes to the scene
- Orbit the view by dragging the mouse
- Zoom with the mouse wheel
- No Python, Unity, or desktop installation required

## Run locally

Open `index.html` in a modern browser with WebGL enabled. For best results, use a local static web server or publish the repository with GitHub Pages.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Open Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. The Pages URL will appear in Settings > Pages.

This is an early prototype. WebGL availability depends on the browser and graphics driver.
